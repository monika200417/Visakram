# Visakram Way — procedural material textures

`way-concrete.webp`, `way-marble.webp`, `way-timber.webp` and `way-grain.webp`
are **procedurally generated placeholder textures** (FFT noise + domain-warped
veining), original to this project. They give The Visakram Way's SVG
architecture its material tooth. They are not photographs of any Visakram
project and should be replaced by real photography/renders when available
(see `asset` in `src/data/visakramWay.ts`).
